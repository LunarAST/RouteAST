# RouteAST RFC Proposals

This directory contains proposals for amendments and extensions to the RouteAST sub-protocol.

## Process

1. Review the [CONTRIBUTING.md](https://github.com/LunarAST/.github/blob/main/CONTRIBUTING.md) in the `.github` repository.
2. Open a **Protocol Proposal** Issue using the template provided in the organization's issue templates.
3. Once the proposal has received initial feedback from the spec-core team, it may be formalized as a Markdown document in this directory, named `RFC-XXXX.md`.
4. Final approval requires CODEOWNER review.

## Conventions

- RFC numbers are sequential and assigned upon acceptance as a proposal document in this directory.
- All proposals must align with the [LunarAST Ecosystem Mother Specification](https://github.com/LunarAST/.github/blob/main/docs/ecosystem-whitepaper-v1.0.md).
- Naming conventions follow the Google JSON Style Guide (`camelCase` for properties, `kebab-case` for filenames).
